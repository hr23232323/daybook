## [0.1.0] - 2026-07-28

First public preview.

### Added

- Local SQLite ledger with deduplicated CSV, OFX, and QFX imports.
- Optional SimpleFIN synchronization.
- Auditable statements, spending flows, calendar views, and deterministic discoveries.
- Optional model-agnostic advisor with read-only tools and adjustable thinking levels.
- Structured coach insights grounded in transaction data.
- Realistic fictional data generator for evaluation and development.
- Contributor guide, issue forms, security policy, CI, and dependency updates.

### Changed

- Rebranded the project as Daybook with the Midnight Ledger visual system.
- Improved first-run guidance, advisor loading feedback, response formatting, and
  performance reporting.
